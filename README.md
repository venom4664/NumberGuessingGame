## 📌 Overview

A console-based game where the computer generates a random number between **1–100**, and the user attempts to guess it within limited attempts.  
The program provides hints (_Too High_, _Too Low_) until the correct number is guessed or the maximum attempts are reached.

---

## ✨ Features

- Random number generation using `java.util.Random`
- User input handling with `java.util.Scanner`
- Feedback messages for each guess
- Attempt tracking with win/loss conditions

---

## ▶️ Run Instructions

```bash
javac NumberGuessingGame.java
java NumberGuessingGame
```
